# COS 201 - Computer Programming I

This repository contains the practical Java programs for COS 201.

## Project structure

```text
COS201-Programming-I/
├── README.md
├── week01/
│   └── FirstProgram.java
├── week02/
│   ├── HelloWorld.java
│   └── StudentProfile.java
└── week03/
    ├── SimpleCalculator.java
    ├── AverageCalculator.java
    └── ItemCost.java
```

## Requirements
- Java Development Kit (JDK)
- Visual Studio Code (or another Java editor)
- Git and a GitHub account for version control and submission

## How to run a program

Open the terminal in the folder containing the `.java` file.

Compile:
```bash
javac FileName.java
```

Run:
```bash
java ClassName
```

For example, to run the Week 3 calculator:
```bash
cd week03
javac SimpleCalculator.java
java SimpleCalculator
```

## Programs

### Week 1
- `FirstProgram.java`: Displays introductory messages.

### Week 2
- `HelloWorld.java`: Displays a welcome message.
- `StudentProfile.java`: Stores and displays a student's profile.

### Week 3
- `SimpleCalculator.java`: Adds, subtracts, multiplies and divides two numbers.
- `AverageCalculator.java`: Calculates the total and average of three course scores.
- `ItemCost.java`: Calculates the total cost using quantity and unit price.
